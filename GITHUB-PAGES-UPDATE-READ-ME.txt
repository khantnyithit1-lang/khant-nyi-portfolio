SITE PRIVATE?
- On GitHub Free, GitHub Pages needs a PUBLIC repository.
- A private repository cannot be made public by uploading website code.
- Check Settings > General > Danger Zone > Change repository visibility.
- CAUTION: making a repository public exposes all its files to others. Verify
  it contains no secrets, credentials, private data or unrelated private files.
- If you don't want public source code, consider Netlify/Vercel static hosting.
